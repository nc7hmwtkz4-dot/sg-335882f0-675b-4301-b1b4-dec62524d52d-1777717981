## Notes
Création de la page dynamique affichant le contenu complet d'un article. C'est ici que l'optimisation pour le partage sur les réseaux sociaux (Facebook, LinkedIn) doit être intégrée, via les balises OpenGraph.

## Checklist
- [ ] Créer une page dynamique capable d'afficher n'importe quel article en fonction de son URL (slug).
- [ ] Appliquer la même restriction de sécurité (feature flag) que pour la page principale : masquer l'article si la fonctionnalité est inactive.
- [ ] Configurer les balises SEO (titre, description) et OpenGraph (og:image, og:title, og:description, og:url) spécifiquement pour l'article en cours de lecture, afin de garantir un affichage parfait lors du partage sur LinkedIn ou Facebook.
- [ ] Mettre en page le contenu de l'article avec un design centré sur le confort de lecture (largeur contrainte, typographie claire).
- [ ] Prévoir des styles pour l'intégration de médias dans le corps du texte (images avec légendes, vidéos).

## Acceptance
- Les partages sur les réseaux sociaux génèrent un aperçu avec la bonne image et le bon titre.
- Le texte est lisible et aéré.
